# Dependency repair — 24 October 2026

Issue #205 records the failed baseline audits. The repair branch pins Zod
4.6.7 and OpenAI SDK 6.0.0 in the root and standalone app. SDK 6.0.0 is the
first v6 release and explicitly supports Zod 4; it is not a claim to use the
latest SDK. The separately metered AI gateway uses its existing transport and
is not activated or reconfigured by this change.

All resolved root/app Zod copies are checked; there is no first-party switch
to `zod/v3` to conceal the old implementation. Existing record schemas already
supply both key and value arguments. Authentication, notes, tRPC and Omega
contracts must pass against v4 before merge; do not infer compatibility from
a package-install result. Bounded collections need explicit limits even with
the upstream patch. Unreviewed legacy provider routes remain closed.

The isolated edge package keeps Wrangler 4.152.0 and overrides only Miniflare's
Undici child to 7.30.1. Its lockfile was regenerated by npm after a lock-only
pass retained the older child. Version comparison shows this is the only edge
package version changed. Worker dry-run validation is required; no Cloudflare
deployment or DNS change is part of this repair.

Root/app npm and Bun locks were regenerated by their package managers without
dependency lifecycle scripts. Root changes remove obsolete SDK transport
packages and deduplicate Zod; npm also records previously absent optional
Tailwind WASI subdependencies. Review the committed diff. No integrity hashes
were invented, no audit exclusions added, and no `audit fix --force` was used.

A temporary, fixed-branch-only resolution workflow was removed before opening
the release PR. It could commit only the three manifests and four lockfiles to
the repair branch, checked its expected remote head and could not merge or
write main through its commands. The permanent regression workflow is read-only.

## Evidence required

- Installed-tree root production/full, standalone app, desktop, Bun, edge and
  resolved Python audits at the final PR revision; prior clean reports expire.
- New collection short-circuit and SDK synthetic-transport regressions, existing
  web/browser contracts, scoped types, actual production-container startup and
  relevant disposable MySQL/auth/restore fixtures.
- Exact-revision Railway SUCCESS and public release checks after an approved
  merge. A passing audit does not establish incident clearance, a production
  restore, a paid AI reply, merchant readiness or full product completion.

Initial candidate lock audits passed in isolated run 40052387720. Full final-head
CI and production evidence are recorded in the PR and continuation issue #202;
