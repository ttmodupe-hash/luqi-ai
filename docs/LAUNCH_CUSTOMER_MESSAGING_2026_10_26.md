## First-user script — operator supervised, no private content in tickets

1. Confirm the user explicitly agrees to a pilot, understands the limitations and has a verified private support route.
2. On a real phone, open `/#/start` at the **verified** hostname. Check readable layout, keyboard navigation and that the advertised tools actually load.
3. Without an account, use the pendulum and a local calculator; check results against a simple manual calculation. Use only non-sensitive input.
4. With a **designated human-owned disposable account**, test sign-up and sign-in once; do not auto-retry uncertain registration outcomes.
5. Save an ordinary test note, reload, sign in again, export, delete, sign out and check private content is no longer visible. Test account separation only with the designated owners' explicit consent.
6. Test the silent studio preview and a locally exported storyboard; do not promise video recording on unsupported browsers.
7. If an authorised pilot text request is separately approved, use one ordinary harmless question with provider acknowledgement; record whether an actual reply arrived. Do not infer it from `/v1/readiness`, a green CI job or model metadata.
8. Ask what was useful, confusing or broken. Record **only a redacted issue category, device/browser, route, timestamp, and permissioned contact reference** in a private operator record. Do not paste email addresses, account content, prompts, tokens, screenshots of notes or payment data into public GitHub issues.

## Questions people may ask

**Is LUQI free?** The current pilot tools can be explored without buying a subscription. Some features require an account; AI text has a separate limited allowance and may be unavailable. Paid plans are not active.

**Can LUQI generate a seven-minute voice-acted cartoon?** Not in the current pilot. The reviewed local studio supports a six-scene 90-second **silent** animation/storyboard, subject to browser recording support. Generative voice/video and automatic posting are not ready.

**Can Omega autonomously run tasks for me?** No live autonomous worker execution is promised. The local calculators and supported drafting tools are distinct from production agents.

**Are notes private?** Account access controls are present, but storage administrators can access server-held notes and backups may retain deleted copies for a time. Do not store sensitive material during this limited pilot. See the published privacy page for current details.

**Can I pay for a subscription now?** No. LUQI will only offer paid products after verified merchant setup, published terms, receipt/refund handling, support, measured AI costs and owner approval.

**Where do I report a problem?** Use only the private contact channel the operator has independently verified. Public GitHub issues must not include private account details. Until a verified contact exists, do not expand the invitation group.
