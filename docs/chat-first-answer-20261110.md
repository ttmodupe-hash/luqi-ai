# First-answer quality correction

A three-turn live guest conversation correctly calculated 20 break-even washes
and R500 profit for 30 washes, but initially called contribution profit, invented
an equipment allowance and asserted that mobile operation avoided permits. The
model qualified the permit claim only when challenged.

The shared server-owned response policy now requires these distinctions in the
first reply: contribution versus profit after fixed costs, startup purchases
versus recurring break-even costs, and quotes versus explicitly hypothetical
allowances. Plans must check equipment, access and permission before operations.
Mobile, home-based or private-site work must not be assumed exempt from local
requirements. Without current authoritative evidence supplied in the request,
the answer must identify the uncertainty and relevant authority.

The same policy reaches guest Gemini and signed-in Gemini/OpenAI. Transport
regressions check policy inclusion, matching guest token counting, and unchanged
single-attempt reservation and output limits. They prove the request contract,
not guaranteed model behaviour. No browsing or external verification is added.
No extra inference, retry, model, output-token limit, quota or billing change is
introduced. Added system text is included in the existing guest token count.
