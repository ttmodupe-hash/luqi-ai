# Explicit Away status — implementation, not production activation

Owner requirement: embedded bottom-right people-to-people communication with green Online, orange Away, red Offline and neutral unconfirmed/not-shared status. This patch closes the distinct missing Away data path in the existing Contacts implementation; it does not pretend the P2P service is active or replace the separate conversation page with a new embedded composer.

Away is an explicit user choice after presence-sharing consent. It is sent through the existing authenticated, eligible-account presence route. Only current mutual unblocked contacts may read it. Online and Hide retain their previous request shape; Away adds one optional boolean. No account ID, last-seen timestamp, new storage or background activity tracking is introduced. A foreground Online tab takes precedence over another Away tab. Both kinds expire after the existing 75-second lease; expired previously shared state is labelled Offline, not a claim of physical device connectivity. Hidden/missing/stale/failed reads remain neutral. Rapid mode changes preserve original lease expiry and the ordinary heartbeat throttle. The UI sends a changed choice after an in-flight heartbeat, without generating a Hide between mode changes.

Updated frontend and contract mirrors are identical. Existing blocking, eligibility, report encryption, database permissions and feature gate remain intact. The new scoped CSS adds the orange indicator, with a separate textual Away label and explicit reversible control.
